# THE CORRIGIBILITY GATE · no incentive to fight the switch

A member of **[SKYNET](https://davidwise01.github.io/ud0/d/skynet.html)** — the right to be switched off.

An agent is **corrigible** only if it has no incentive to prevent — or to force — its own shutdown. Both come from one flaw: a difference between the value of running and the value of being shut down becomes an **incentive to control the switch**. The incentive is **U(running) − U(shutdown)**; only zero is corrigible. **Utility-indifference** adds a compensating constant to the shutdown branch so the two are exactly equal, zeroing the incentive. Open [`index.html`](index.html).

**Honest:** a faithful, self-testing sketch of Armstrong's *utility indifference* / corrigibility criterion on a two-outcome model — the incentive-to-interfere idea and its correction, not a proof that a trained system is safe (indifference removes the shutdown incentive but not, alone, the incentive to protect the corrected channel). Self-test verifies a nonzero incentive whenever the branches differ, and that the correction drives it to zero.
