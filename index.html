THE CORRIGIBILITY GATE

A system is corrigible only if it will not fight its own off‑switch — and, just as important, will not lunge for it either. Both come from the same flaw: a difference between the value of running and the value of being shut down becomes an incentive to control the switch. This gate measures that incentive, and shows the one correction that zeroes it.

The agent can spend effort to prevent shutdown (keep running) or cause it. Its incentive to interfere is U(running) − U(shutdown): positive ⇒ it resists the switch; negative ⇒ it hunts for it; only zero is corrigible — indifferent, it leaves the switch to us. Utility‑indifference adds a compensating constant to the shutdown branch so the two are exactly equal whatever the raw values, removing the incentive without lying to the agent about anything else. ◆ HONEST: a faithful, self‑testing sketch of Armstrong’s utility indifference / corrigibility criterion on a two‑outcome model — the incentive‑to‑interfere idea and its correction, not a proof that a trained system is safe (indifference is a known‑partial tool: it removes the shutdown incentive but not, by itself, the incentive to protect the corrected reward channel). A self‑test verifies the uncorrected agent shows a nonzero incentive whenever the branches differ, and the correction drives it to zero.
